# Font del compositore

- `HankenGrotesk-Bold.ttf` (700) — titolo dell'intestazione («Opus 5.5»)
- `HankenGrotesk-SemiBold.ttf` (600) — disponibile per etichette più leggere

Hanken Grotesk è distribuito con licenza SIL Open Font License 1.1 (vedi `OFL.txt`).
File statici scaricati da Google Fonts (versione 3.013).

Scelto confrontando 60 famiglie sans OFL sul titolo del riferimento: a parità di
dimensione e tracking è quello con l'errore di sagoma più basso (≈3% di copertura media,
contro ≥5% di DM Sans, Albert Sans, Figtree, Manrope…).
